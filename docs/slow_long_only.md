# Slowed-down long-only test (in-sample 2005-01-01 .. 2018-12-31)

Question: does any of the strongest daily-IC alphas survive as a long-only, 20-name, slow-rebalanced book at a flat C$9.99 per ticket (the retail broker)?

## What was run

- Code: `scripts/slow_long_only.py` calling `alpha101.evaluate.composite_backtest(..., book="long_only", n_long=20)` and `alpha101.costs.CostModel`; library unchanged. Holdout locked (`RunConfig` default, 2019+ never read).
- Panel/universe/RunConfig: `default` run defaults (raw basis, close execution, `last_close` delisting, universes `liquidity_top500_us@20261019` and `liquidity_top200_ca@20261019`).
- Selection: per market, top 10 of 101 alphas by |NW t| of daily rank IC at horizon 5, read from the persisted `alpha_ic` rows of default run `20261019T2057Z-78fe86b` (in-sample rows only, date < 2019-01-01; NW lags = horizon). Weight -1 for negative mean IC. The h=21 top 10 is listed for comparison but not traded. Raw selection: `docs/slow_long_only_selection.json`.
- Strategies: each of the 10 alphas plus the equal-sign-weighted composite, per market: 11 x rebalance {W-FRI, M, Q} x book {C$100k, C$250k} x 2 markets = 132 backtests. All 132 ran (no size dropped).
- Period aliases: pandas 3.0.2 `to_period` rejects `ME`/`QE`, so `M` (month-end) and `Q` (quarter-end) were used.
- Costs: commission 9.99 with `notional_per_name = book / 20` (C$5k / C$12.5k tickets), default half-spreads (US 3 bps, CA 8 bps), `fx_mode="none"` as in the default run (no FX cost is applied to US; an FX-desk tiered cost would add roughly 168 bps per conversion at C$5k tickets and make the US rows worse).
- Metrics (in-sample days with finite gross/net/benchmark): gross, net, benchmark (equal-weight in-universe names) are arithmetic daily mean x 252; active = net - benchmark with Newey-West t (21 lags) and 95% CI = mean +/- 1.96 se; turnover = mean one-way turnover per rebalance (library `turnover`); tickets/yr = `n_trades` per year; commission drag = tickets/yr x 9.99 / book in bps; break-even fee = 9.99 + active_ann / (tickets_per_year / book), i.e. the flat fee at which active = 0 (negative: active < 0 even at zero commission).
- Fee accounting check: the library charges commission pro rata to traded value. ## Caveats

- Top 10 were chosen on the same in-sample window they are evaluated on, so every number is optimistic.
- Active return against the same-universe equal-weight benchmark cancels part of the survivorship bias (the universes are built from today's constituents) but not all of it. The default run measured a US universe-vs-RSP gap of +4.8%/yr, so the US benchmark itself is inflated; the CA universe has no point-in-time history.
- Benchmark is gross of costs and rebalanced daily; the long-only book is not.
- One-way turnover is 0.53-0.96 per rebalance even quarterly: these signals churn fast, so slowing the rebalance does not make them slow.
